# Controle de Pontos de Conexão — NPCs

## Escala de conexão

| Pontos | Significado                                                                                               |
| ------ | --------------------------------------------------------------------------------------------------------- |
| **1**  | Conhecimento e vínculo comunitário. Existe familiaridade e convivência, mas pouca proximidade individual. |
| **2**  | Vínculo próximo. Existe uma relação frequente, confiança, amizade ou colaboração importante.              |
| **3**  | Vínculo muito forte. Relação familiar, afetiva ou extremamente importante para a história do personagem.  |

## 4. Observações para o mestre

- Cada ponto significa 1d6 a mais que o player pode usar a mais em testes no NPC/player.
    
- Caso algum NPC morra, cada ponto de conexão significa -3 de determinação por ponto.
    
- Pode entregar um ponto de conexão apenas 1 vez por cena.
    
- Pode negativar pontos de conexão.
